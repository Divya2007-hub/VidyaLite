# VidyaLite

Offline-First Adaptive Learning Platform

Built by Team PIXEL for wHACKiest 2026.

## Overview

VidyaLite is a lightweight, offline-first adaptive learning web application.

## Tech Stack

- HTML5
- Tailwind CSS
- Lucide Icons
- Google Fonts (Inter, Plus Jakarta Sans, Noto Sans Kannada, Noto Sans Devanagari)

## Live Demo

Open `index.html` in a browser to view the application.
