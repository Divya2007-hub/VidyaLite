The Challenge

Why Rural Classrooms Are Left Behind by Conventional EdTech

Rural primary and secondary students lose critical learning time when connectivity drops and one-size-fits-all digital tools fail multi-grade realities.

Unreliable Connectivity

Video-heavy apps buffer endlessly or consume expensive mobile data, halting learning whenever rural networks drop.

Multi-Grade Classrooms

A single rural teacher often manages Grades 5–8 simultaneously, making individual 1-on-1 remediation nearly impossible.

ASER Foundational Gaps

ASER reports repeatedly reveal persistent gaps in foundational numeracy and reading that widen without targeted practice.

Static Broadcast Limits

DIKSHA and TV/radio lessons are passive and one-size-fits-all—lacking regional adaptive practice and teacher-level gap insights.

System Design

VidyaLite Offline-First Architecture

Local-first execution on low-end Android phones paired with lightweight delta synchronization and cloud AI/voice pipelines.

STEP 1 · EDGE DEVICE LAYER

Student Device (React PWA + Service Worker + IndexedDB)

Caches NCERT/state-board lesson packs, regional ElevenLabs audio clips, and the lightweight Elo adaptive engine directly on the phone. Every answer writes locally to IndexedDB with zero network dependency.

Latency: < 15ms (Local)
Technology Stack

Built for Low-End Hardware & Low-Bandwidth Networks

Frontend

React + Vite PWA, Tailwind

Installable, ultra-lightweight responsive interface engineered to run smoothly on entry-level Android phones.

Offline Layer

Service Workers + IndexedDB

Pre-caches lesson bundles and buffers student responses locally with timestamp-based conflict resolution.

Backend

FastAPI (Python)

High-throughput async sync API handling compressed delta payloads and seamless ML/LLM service orchestration.

Database

PostgreSQL / SQLite

Structured storage for curriculum packs and synced student telemetry; SQLite supports portable local edge nodes.

AI / ML

Elo / IRT + Small LLM

Item-Response Theory / Elo rating dynamically selects optimal difficulty while a small LLM generates concise hints.

Voice + Cloud

ElevenLabs + AWS (S3/EC2)

Natural regional-language voice synthesis in Kannada & Hindi packaged into compressed S3 content bundles.

24-Hour MVP Scope, Feasibility & Go-To-Market
